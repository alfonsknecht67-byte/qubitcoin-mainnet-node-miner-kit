01 / Choose how you participate

Three paths. One clear starting point.

02 / Your selected setup

Miner only: a direct route to pool mining.

The GPU miner runs directly in Windows or native Linux. No local node or blockchain synchronization is required.

  1. Extract the source ZIP into a new folder. Install 64-bit Python 3.10+ if needed.
  2. Open START.cmd on Windows or bash start.sh on Ubuntu. Choose 1 — Miner only.
  3. Get the verified original miner, list GPU IDs and enter your Qubitcoin receiving address and pool.
  4. Review the settings, choose Start and type START QTC. Use Status to inspect accepted shares.

Changing a setting or choosing a path never starts mining automatically.

04 / Know what each part does

Clear roles.
Separate installations.

The node independently checks the blockchain. The GPU miner sends QHash work to your selected pool. Pool mining works independently of local node synchronization.

A node alone earns no mining rewards and does not increase GPU hashrate. This kit does not offer local solo mining.

Windows node requirements

The optional node uses its own Ubuntu WSL distribution named QTC-Mainnet-Kit. Prepare it once using NODE-GUIDE.md. Existing distributions are never selected automatically.

Software, fees and resource use

WildRig Multi 0.52.1 comes separately from its original release and is checked by SHA-256. Its QHash developer fee is 2%, separate from pool fees. Node compilation and initial synchronization use time, disk, CPU and network resources.

Node source and storage

The optional node is built from pinned Qubitcoin source with the community CPU-validation patch. Wallet support is disabled. It uses a separate pruned blockchain directory, local-only RPC and outbound peers. No services or autostart are added.

Start with the guide. Keep control.

Use a receiving address from your own Qubitcoin mainnet wallet. The kit does not ask for private keys, seed phrases or node credentials. GPU IDs, threads, intensity and temperature thresholds can be changed in the menu after stopping the kit miner.
